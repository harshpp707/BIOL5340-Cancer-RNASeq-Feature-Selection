# AI Usage Documentation - BIOL 5340 Final Project

**Project Title:** Evaluating Feature Selection Methods For Cancer Type Classification using RNA Seq Data  
**Team Members:** Harsh Patel, Omkar Juvatkar, Pritesh Das  

In compliance with course transparency guidelines, this document records the utilization of artificial intelligence tools during the development of our project codebase, analytical pipeline, and written reports.

## 1. Summary of AI Tools Used
- **Tools Utilized:** Google Gemini, Anthropic Claude, OpenAI ChatGPT.
- **Primary Purposes:**
  - Brainstorming and structuring the experimental comparative framework (evaluating ANOVA F-test, Mutual Information, and L1-regularized logistic regression against the full-feature baseline).
  - Troubleshooting Python, pandas, and scikit-learn syntax within Jupyter notebooks (`01_Data_Preparation.ipynb`, `02_Pilot_SVM.ipynb`).
  - Assisting with structuring academic phrasing and formatting for project proposals and draft reports.

## 2. Verification and Quality Control
- **Manual Review:** Every line of AI-assisted code or text was independently reviewed, understood, and modified by team members prior to integration.
- **Empirical Validation:** Correctness was established strictly through empirical code execution and validation checks within stratified cross-validation folds, rather than relying on automated or blind AI agreement.
- **Data Privacy & Ethics:** No proprietary, restricted, or sensitive patient/clinical data was processed using external AI tools; all analyses were conducted on the publicly available open-access UCI Gene Expression Cancer RNA-seq benchmark dataset (Dataset ID: 401).
